# 快速开始：把这个插件上架到 DSH 插件市场

这个包里已经准备好上架需要的全部材料，你只需要做 5 件事。

> 市场（dsh-market）的列表来自 GitHub 仓库 `awesome-dsh-plugin/awesome-dsh-plugin`。
> 列表数据写在 `data/plugins/` 下，**一个插件一个 YAML 文件**。
> 所以「上架」= 一个公开的插件仓库 + 给那个仓库提一个只新增 1 个文件的 PR。

## 第 1 步：把 `plugin/` 推到一个公开的 GitHub 仓库

你的电脑上目前没有 GitHub 账号、没有 Git 配置（也检查过 `.gitconfig` / `.ssh` / npm 配置，都不存在），
所以先注册一个 GitHub 账号（免费）。然后二选一：

**方式 A：网页上传（不用装 Git，最省事）**

1. 打开 https://github.com/new
2. Repository name 填 `dsh-whale-persona`，可见性选 **Public**，点 Create repository
3. 在空仓库页面点 **uploading an existing file**
4. 把本包 `plugin/` 目录里的**所有内容**（是里面的文件，不是 plugin 这个文件夹）拖进去
5. Commit changes

**方式 B：Git 命令（需要先装 Git for Windows）**

```sh
cd plugin
git init
git add .
git commit -m "feat: dsh-whale-persona v1.1.0"
git branch -M main
git remote add origin https://github.com/<你的GitHub用户名>/dsh-whale-persona.git
git push -u origin main
```

## 第 2 步：给仓库加 `dsh-plugin` topic

打开仓库首页 → 右侧 About 旁的齿轮 → Topics 填 `dsh-plugin` → 保存。
（CI 会检查这个 topic；另外仓库必须**创建满 1 天**才能提 PR，这是自动检查的。）

## 第 3 步（推荐但不是必须）：发布到 npm

贡献指南明确说：发了 npm 包的用户能一条命令装好（预构建安装会跳过 `allowBuilds` 构建授权）。

```sh
npm login
cd plugin
npm publish --access public
```

包名默认 `dsh-whale-persona`。如果 npm 上已被占用，改 `package.json` 的 `name`（例如 `dsh-whale-persona-cn`），
同时把 `cordis.patch.yml` 里的 `name:` 改成同一个新包名（插件 id `id:` 可以保持不变，它是你自己的标识）。

本包还附带了打好的 npm 包，也可以直接发布它：

```sh
npm publish npm-package/dsh-whale-persona-1.1.0.tgz
```

## 第 4 步：生成市场条目文件（1 个文件）

```sh
node market-entry/make-entry.mjs <你的GitHub用户名> dsh-whale-persona
```

它会生成 `market-entry/data-plugins/<你的GitHub用户名>__dsh-whale-persona.yml`。
（不想跑脚本也可以：把 `market-entry/条目模板.yml` 里的 `<你的GitHub用户名>` 全部替换后，另存为
`<你的GitHub用户名>__dsh-whale-persona.yml`。）

## 第 5 步：提 PR

1. 打开 https://github.com/awesome-dsh-plugin/awesome-dsh-plugin → 右上角 **Fork**
2. 在你 fork 的仓库里：**Add file → Create new file**，文件名填
   `data/plugins/<你的GitHub用户名>__dsh-whale-persona.yml`，把上一步的内容粘进去，Commit
3. 回到上游仓库 → **Pull requests → New pull request** → 选你的分支
4. 标题 `Add dsh-whale-persona`，正文直接粘贴 `market-entry/PR-正文.md` 的内容
5. 等 CI：检查 4 项（条目数 ≤3、`package.json` 里有 `dsh.bundle`、仓库创建满 1 天、awesome-lint + 站点构建）
6. 合并后网站自动重建，之后在 DSH 的插件市场里就能搜到（通常次日生效）

更细的说明、自查表、常见被打回的原因，看 `上架指南.md`。
